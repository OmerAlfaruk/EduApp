## 2025-02-13 - State-Appropriate Tooltips for Accessible Flutter IconButtons
**Learning:** Icon-only buttons (like `IconButton`) do not inherently have descriptive semantic labels, which severely impacts screen reader accessibility. By specifying a dynamic or state-appropriate `tooltip` property in Flutter, we provide both a visible helper tooltip on hover and a primary semantic label for screen readers. Toggle buttons (such as password visibility toggle) must dynamically update their tooltips to reflect the current state (e.g. "Show password" vs "Hide password") to avoid conveying confusing, outdated context to users.
**Action:** Always provide state-aware, descriptive `tooltip` properties for all `IconButton` and custom icon buttons in Flutter. Use dynamic conditions if the icon state toggles to keep the semantic label in perfect sync with the interface.
